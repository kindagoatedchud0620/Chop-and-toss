# CHOP & TOSS

A chaotic 3D co-op cooking game for two chefs on one laptop keyboard. Each 3 minute shift drops you into one of four asymmetric kitchens. Every shift rolls a menu of 3 dishes out of 6, so no two shifts ask for the same food. Chop, cook, plate and serve them as many times as you can.

## Run it

```bash
node server.js
```

Then open http://localhost:4921 (Node 18 or newer, no install step, no build step, everything is served from local files).

## Controls

| | Player 1 (cat, left) | Player 2 (raccoon, right) |
|---|---|---|
| Move | W A S D | Arrow keys |
| Pick up, drop, plate | Space | J |
| Chop, throw, wash, spray | E | K |
| Dash | Left Shift | L |

`M` toggles sound (off by default). `R` restarts in a new random kitchen.

## The six dishes (3 are rolled per shift)

| Dish | Recipe |
|---|---|
| Tomato Soup | 3 chopped tomatoes boiled in a pot |
| Classic Burger | bun + chopped meat fried in a pan + chopped lettuce |
| Fish & Chips | chopped fish fried in a pan + chopped potato fried in a pan |
| Garden Salad | chopped lettuce + chopped tomato, straight onto a plate |
| Fish Burger | bun + chopped fish fried in a pan + chopped lettuce |
| Hearty Stew | chopped meat + chopped potato + chopped tomato boiled together in a pot |

The title screen shows the menu rolled for the next shift. R rolls a new kitchen and a new menu.

## VS mode (Tug-of-War)

Pick **VS MODE** on the title screen (or open `?mode=vs`). The two chefs compete instead of cooking together:

- Each chef serves only at their own hatch: the cat at the orange left hatch, the raccoon at the purple right hatch. Both race for the same tickets.
- A shared tug-of-war bar starts at 50 : 50. Each matching dish pulls it 10 percent your way. Pull it all the way for a K.O. VICTORY. At 0:00 the bigger side wins.
- Dash into your rival (Left Shift or L) to stun them for 1.5 s and knock whatever they hold onto the floor. The dash has a 3 s cooldown in VS.
- Every 40 s one ticket becomes a flashing gold VIP ticket with a siren. It drains twice as fast and pulls the bar 30 percent.
- `?mode=vs&bot` makes both chefs AI; `?mode=vs&bot=2` lets you play the cat against the AI raccoon (`bot=1` for the reverse).

## End of shift

- The best shift score is kept in the browser (`localStorage` key `chop-and-toss-best`) and shown on the title screen.
- A standard ending pulls the camera back, plays the exhausted clip on both chefs (panting, wiping a brow), then tallies the score and stamps 1 to 3 stars.
- A new best triggers the Record Breaker ending: the camera pushes in, the chefs jump and high-five on a loop, golden confetti and order tickets rain over the kitchen, an FM synth fanfare cuts in over the buzzer, and the new score smashes the old best score off the panel under a pulsing NEW SHIFT RECORD! banner.
- `?time=N` (3 to 180) shortens the shift for testing.

## The four kitchens

1. **Split River Rafts**: prep on the left raft, cook on the right, throw everything across the river.
2. **Arcane Portal Kitchen**: two rooms split by a wall, joined by blue and orange portal pairs.
3. **Shifting Counter Bistro**: the island with the stoves and boards slides every 12 seconds.
4. **Conveyor Belt Gauntlet**: the top belt carries food right, the bottom belt carries dirty plates left.

## URL switches

| Switch | Effect |
|---|---|
| `?start` | skip the title screen |
| `?map=0..3` | force a kitchen (normal play is random) |
| `?bot` | both chefs are played by the AI (`?bot=1` or `?bot=2` for one AI partner) |
| `?hold` | no real-time loop. Call `window.__step(n)` to advance n frames of 1/60 s and draw, `window.__sim(n)` to advance without drawing |
| `?seed=N` | fixed random seed |
| `?dishes=a,b,c` | force the menu: 3 distinct pool indices (0 soup, 1 burger, 2 fish & chips, 3 salad, 4 fish burger, 5 stew) |

## Project layout

```
index.html, css/          page, HUD and title screen (plain DOM, fonts in fonts/)
js/sim.js                 the whole game simulation, fixed 1/60 s steps, no rendering
js/bot.js                 the two-chef AI (drives the same inputs as a player)
js/view.js, fx.js, gfx.js three.js scene, particles, shared lighting patch, post-processing
js/audio.js               every sound, synthesised with WebAudio
js/data.js                recipes, tuning numbers and the four maps as ASCII grids
blender/                  Python scripts that build every model with headless Blender
assets/models/*.glb       the exported models (one .glb each)
vendor/three/             three.js r180 and the few addons used
tools/                    headless Chrome drivers and tests (DevTools protocol, no dependencies)
```

## Rebuilding the models

Every model is generated by the scripts in `blender/` and exported as one `.glb`:

```bash
blender --background --python blender/build_all.py            # with the Blender app
python blender/build_all.py [model_name ...]                  # with the bpy Python module
```

## Tests

With the server running:

```bash
node tools/simtest.mjs all 1     # pure simulation, AI plays a full round on each map (no browser)
node tools/prove.mjs             # headless Chrome: full rounds, forced fire, washing, random restarts
node tools/keytest.mjs           # real key events for both players at once in the real-time loop
node tools/choptest.mjs          # real E and K holds chop at the same time
node tools/finale-verify.mjs     # end of shift: standard and record endings, localStorage, stills in out/stills-v3/
node tools/vstest.mjs            # VS rules: layouts, tug, K.O., stun, VIP (no browser)
node tools/simtest.mjs all 1 --vs   # VS bots on every map (no browser)
node tools/vs-final.mjs          # VS end to end: real keys, bot rounds, stills in out/stills-vs/
node tools/dishtest.mjs          # menu roll, pot rules and the three new dishes (no browser)
node tools/bottest.mjs           # bot routing table and all six dishes served (no browser)
node tools/simtest.mjs all 1 --menus   # every menu on every map with the AI (no browser)
node tools/powcheck.mjs          # lists every pow() in every compiled shader
node tools/perf.mjs              # frame rate, draw calls and triangles of the real-time loop
node tools/audiotest.mjs         # sound code paths against a silent mock (no audio device)
```

On macOS run the Chrome tools with `CHROME_GL=metal` (and `CHROME=/path/to/Chrome`).
